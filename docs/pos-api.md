# POS API — προσφορές στο ταμείο καταστήματος

Το ταμείο (POS) ενός καταστήματος ρωτά την **ίδια μηχανή προσφορών** με το e-shop και παίρνει, ανά γραμμή, τις εκπτώσεις
και τους κωδικούς προσφορών όπως θα γραφτούν στο παραστατικό SoftOne. **Μόνο υπολογισμός**: δεν γράφεται παραγγελία,
δεν μετρούν χρήσεις / budget, δεν γίνεται καμία κλήση στο SoftOne.

## Πρόσβαση
- Κλειδί από **Ρυθμίσεις → API keys** (μόνο super-admin) με scope `pos`. Το κλειδί φαίνεται μία φορά· αποθηκεύεται μόνο το hash.
- Header: `Authorization: Bearer eu_…` (ή `x-api-key: eu_…`).

## Αίτημα
`POST /api/pos/v1/quote`
```json
{
  "store": "<erpBranch | id | slug καταστήματος>",
  "lines": [{ "code": "<sku | EAN | MTRL>", "qty": 1, "price": 349.00 }],
  "coupon": "WELCOME10",
  "email": "pelatis@example.gr",
  "payment": "card"
}
```
- `price` (προαιρετικό): τιμή ραφιού του καταστήματος με ΦΠΑ. Χωρίς αυτήν χρησιμοποιείται η τιμή του e-shop.
- `email` (προαιρετικό): για προσωπικούς κωδικούς, «πρώτη αγορά», κοινά πελατών.
- `payment`: `card | no-card | iris | bank | cod | store | apple | google` (για εκπτώσεις τρόπου πληρωμής).

## Απάντηση (συντομευμένη)
```json
{
  "ok": true,
  "store": { "id": "…", "name": "…", "erpBranch": "…" },
  "lines": [{ "code": "…", "MTRL": "152631", "qty": 1, "PRICE": 349, "NODSCLNVAL": 349, "DISC1VAL": 34.9, "DISC2VAL": 0, "DISC3VAL": 0, "LINEVAL": 314.1, "COMMENTS": "CMP-2026-014 v2", "promotions": [ … ] }],
  "totals": { "list": 349, "promotions": 34.9, "coupon": 0, "payment": 0, "total": 314.1 },
  "coupon": { "applied": null, "message": null },
  "gifts": [], "hints": [], "applied": [{ "code": "CMP-2026-014", "name": "…", "amount": 34.9 }],
  "unknown": []
}
```

## Ποιες προσφορές ισχύουν στο ταμείο
- Όσες έχουν κανάλι «Παντού» ή «Μόνο στο ταμείο».
- Όσες έχουν «Μόνο σε συγκεκριμένα καταστήματα» ισχύουν μόνο στα καταστήματα αυτά.
- Οι «Μόνο αποστολή» / «Μόνο παραλαβή» δεν ισχύουν στο ταμείο.

## Εκκρεμεί (μαζί με την ενεργοποίηση του SoftOne)
- Καταγραφή της πώλησης του ταμείου (χρήσεις, budget, αναφορές): θα έρθει από τα παραστατικά καταστήματος του SoftOne.
