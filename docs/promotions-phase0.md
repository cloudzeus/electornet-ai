# Προσφορές · Φάση 0 (θεμέλια)

Πρόταση σχεδιασμού: artifact «Μηχανή Προσφορών Euronics». Η Φάση 0 φτιάχνει ό,τι χρειάζεται κάθε προσφορά.

## Τι υπάρχει
| Κομμάτι | Πού | Σημείωση |
|---|---|---|
| Δεδομένα | `prisma/schema.prisma` | `Promotion`, `PromotionVersion`, `PromotionTarget`, `Coupon`, `PromotionUsage` · στην `OrderLine` τιμή καταλόγου και εκπτώσεις ανά είδος · `ErpSync.payload` |
| Μηχανή | `lib/promo/engine.ts` | καθαρή συνάρτηση σε λεπτά· 9 τεστ (`npm test`) |
| Σύνδεση με βάση | `lib/promo/server.ts` | ενεργές προσφορές (cache 15 s), γραμμές από τα πραγματικά προϊόντα, κουπόνια, Omnibus (χαμηλότερη τιμή 30 ημερών) |
| Καλάθι στον server | `lib/cart/server.ts` · `/api/cart` | cookie `eu_cart` για επισκέπτες, δέσιμο με τον πελάτη στη σύνδεση· ο browser καθρεφτίζει το καλάθι του (`CartProvider`) |
| Υπολογισμός checkout | `/api/checkout/quote` | τιμές από τη βάση, υπηρεσίες από τον κατάλογο υπηρεσιών, ποτέ από τον browser |
| Παραγγελία | `lib/checkout/place.ts` · `/api/checkout/place` | μία συναλλαγή· ατομικοί μετρητές χρήσεων / budget· `dryRun` (εκτός production) εκτελεί όλα και τα αναιρεί |
| Παραστατικό SoftOne | `lib/softone/order-doc.ts` | SALDOC + ITELINES, **μόνο σύνθεση** — αποθηκεύεται στο `ErpSync` με status `preview` |

## Κανόνες της μηχανής
1. Μία έκπτωση τιμής ανά γραμμή: η καλύτερη για τον πελάτη· η «αποκλειστική» κερδίζει πάντα και μπλοκάρει κουπόνια στη γραμμή.
2. Κουπόνι καλαθιού κατανεμημένο αναλογικά στις γραμμές (σωστός ΦΠΑ / επιστροφές)· `no-price` = μόνο σε γραμμές χωρίς προσφορά τιμής.
3. Δικλείδες: μέγιστο 40 % έκπτωση ανά γραμμή, ποτέ κάτω από το κόστος όταν είναι γνωστό.
4. `held = true` (ανενεργό μέχρι διευκρίνιση): δεν εφαρμόζεται ποτέ.
5. Ίχνος για κάθε προσφορά που εξετάστηκε, με τον λόγο σε απλά ελληνικά· αποθηκεύεται στην παραγγελία (`Order.promoTrace`).

## Αντιστοίχιση στο SoftOne (επιβεβαιωμένη στην εγκατάσταση Euronics, 2/10/2026)
`PRICE`/`NODSCLNVAL` τιμή καταλόγου · `DISC1VAL` προσφορά τιμής · `DISC2VAL` κουπόνι · `DISC3VAL` τρόπος πληρωμής (Φάση 2) ·
`COMMENTS` κωδικός + έκδοση προσφοράς · `COMMENTS1` όροι. Προτείνονται νέα πεδία `CCCPROMO`, `CCCPROMOVER`.

## Πριν την πραγματική αποστολή στο ERP
- Σειρά παραστατικού παραγγελίας e-shop (Ρυθμίσεις → SoftOne)
- Πελάτης λιανικής (TRDR) για επισκέπτες
- Κωδικοί είδους (MTRL) για τις υπηρεσίες (επέκταση εγγύησης κ.λπ.)
- Δοκιμή σε σειρά δοκιμών και ρητή έγκριση· η κλήση `setData` δεν έχει γραφτεί ακόμα σκόπιμα
