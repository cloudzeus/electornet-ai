# Ερμής — σύμβουλος πωλήσεων πάνω στον πραγματικό κατάλογο

`lib/advisor/engine.ts` · `GET /api/advisor?q=…&prev=…&pid=…&door=…&niche=w,h,d` · σετ ελέγχου `scripts/eval-advisor.ts`

**Αρχή:** το LLM δεν «ξέρει» προϊόντα. Καταλαβαίνει την ερώτηση και εξηγεί· προϊόντα, τιμές, απόθεμα, χαρακτηριστικά και
πολιτική καταστήματος έρχονται ΜΟΝΟ από τη βάση μας (`Product`, `ProductFacetValue`, `ProductDimension`, `EnergyLabel`/EPREL,
`Settings.site.commerce`). Δεν υπάρχει «εκπαίδευση» μοντέλου — όταν αλλάζει ο κατάλογος, αλλάζουν και οι απαντήσεις.

| Βήμα | Ποιος | Τι κάνει |
|---|---|---|
| 1. understand | μικρό γρήγορο μοντέλο (`ADVISOR_ROUTER_MODEL`, προεπιλογή `google/gemini-3.5-flash-lite`) | ερώτηση (+ προηγούμενη, + προϊόν που βλέπει) → τύποι προϊόντος ΑΠΟ ΤΗ ΛΙΣΤΑ του καταλόγου, προϋπολογισμός, μάρκες, όρια χώρου, ανάγκες, προτεραιότητα, κωδικοί μοντέλου, είδος ερώτησης (προϊόν / πολιτική / άσχετο). Η λίστα τύπων συνοδεύεται από τις συχνότερες λέξεις των τίτλων κάθε τύπου («Φριτέζες» = air fryer) |
| 2. mapNeeds | το ίδιο | ανάγκες («9 κιλά», «wifi», «no frost») → ΤΙΜΕΣ φίλτρων που έχει όντως ο τύπος στο ERP. Ό,τι δεν είναι υπαρκτή τιμή πετιέται |
| 3. retrieve | Postgres + pgvector | φίλτρα SQL (τύπος, τιμή, μάρκα, απόθεμα, τιμές φίλτρων, ομογενοποιημένες διαστάσεις) → κατάταξη με σημασιολογική ομοιότητα (έγγραφα v2) + απόθεμα + τιμή → έως 2 ανά μάρκα → 8 υποψήφια. Όταν δεν βγαίνει τίποτα χαλαρώνει (τελευταία ανάγκη → προϋπολογισμός +15 % → μάρκα) και το ΛΕΕΙ |
| 4. compose | κύριο μοντέλο | από τα 8 δελτία στοιχείων διαλέγει έως 3, εξηγεί τη διαφορά τους με νούμερα, κλείνει με μία στοχευμένη ερώτηση. Δείκτες προϊόντων εκτός λίστας απορρίπτονται |

Εφεδρείες: χωρίς κλειδί / πάνω από το ημερήσιο όριο / αποτυχία μοντέλου → κανόνες πάνω στη βάση· χωρίς κατάλογο στη βάση → το παλιό demo.
Έγγραφα vector v2 (`lib/vector/documents.ts`): τιμές φίλτρων, ομογενοποιημένες διαστάσεις, γραμμές ενεργειακής ετικέτας. Όχι τιμή / απόθεμα
(αλλάζουν καθημερινά — φιλτράρονται στη βάση). Ξαναχτίσιμο: `scripts/reindex-vector.ts` (9.081 έγγραφα ≈ $0,20).

Μετρήσεις (22 ερωτήσεις): 21–22/22 σωστές και 100 % γειωμένες (κάθε προϊόν υπάρχει στη βάση με την τιμή της βάσης)· ~$0,007 ανά ερώτηση·
~9 s από το Mac με απομακρυσμένη βάση (≈ 5 s στο μοντέλο, τα υπόλοιπα είναι δίκτυο προς τη βάση — στο staging η βάση είναι δίπλα).
