# Εισαγωγή προϊόντων από «ξένο» Excel: αντιστοίχιση, SoftOne, φωτογραφίες, τιμές με markup

Ημερομηνία: 20/10/2026 · Κατάσταση: σχέδιο εγκρίθηκε ανά ενότητα στη συζήτηση· αναμένει έγκριση του γραπτού spec · UI με ui-ux-pro-max

## 1. Στόχος

Ο διαχειριστής ανεβάζει οποιοδήποτε Excel (τιμοκατάλογο / αρχείο προμηθευτή, όχι δικό μας template), αντιστοιχίζει τις
στήλες του σε πεδία του καταλόγου, και το σύστημα: βρίσκει ποια είδη υπάρχουν ήδη στο SoftOne και συμπληρώνει ό,τι τους
λείπει· ετοιμάζει τα νέα είδη για δημιουργία στο SoftOne με έγκριση· κατεβάζει τις φωτογραφίες από URL και τις ανεβάζει
στο Bunny όπως όλες τις άλλες· υπολογίζει τιμή πώλησης από το κόστος με κανόνες markup.

Αποφάσεις χρήστη (20/10):
- Νέα είδη: **δημιουργία με έγκριση** — λίστα «Νέα είδη προς δημιουργία», δημιουργία μόνο με έγκριση και ανοιχτό
  διακόπτη «Αλλαγές προϊόντων προς SoftOne».
- Υπάρχοντα: **μόνο συμπλήρωση κενών + φωτογραφίες** — ποτέ αντικατάσταση τιμής που υπάρχει.
- Κατηγορία: στήλη με αντιστοίχιση τιμών· ό,τι δεν αντιστοιχίζεται απλώς δεν χρησιμοποιείται (μένει κενό και συμπληρώνεται
  στην έγκριση του νέου είδους).
- Προσέγγιση: **μετατροπέας πάνω στην υπάρχουσα μηχανή** εισαγωγής των templates (lib/catalog/supplier-import.ts,
  supplier-media.ts) — όχι νέα μηχανή εγγραφών.
- Τιμές: **κανόνες markup ανά κατηγορία / μάρκα**, μόνο για νέα είδη και είδη χωρίς τιμή web.

## 2. Τι υπάρχει ήδη (επαναχρησιμοποίηση)

- `parseWorkbook` → `ParsedFile { rows: ParsedRow { fields: Partial<Record<FieldKey,string>>, specs, groupS1Id } }`,
  `planImport(file, opts)` / `applyImport(file, opts, keys)` (σχέδιο χωρίς εγγραφή, εκτέλεση σε παρτίδες, εγγραφή στο
  SoftOne με έλεγχο σύγκρουσης και επαλήθευση, `composeMemo` για τα χαρακτηριστικά στο CCCWREMARKS).
- `planMedia` / `applyMedia` (φωτογραφίες, banners, βίντεο από URL: μόνο δημόσιες διευθύνσεις, WebP, Bunny, βιβλιοθήκη,
  χωρίς ξανακατέβασμα για ίδιο URL).
- `createItem(NewItem)` και `itemCodeTaken` (lib/softone/item-write.ts): setData ITEM, ΦΠΑ / μονάδα / ομάδα / εμπορική
  κατηγορία αντιγράφονται από είδος ίδιου τύπου, ανάγνωση για επαλήθευση· `itemWriteEnabled()` = ο διακόπτης.
- Καθρέφτης SoftOne (`S1Item`), μάρκες, ομάδες χαρακτηριστικών (`S1SpecGroup`), κατηγορίες site.

## 3. Ροή (Κατάλογος → Templates & excel → «Εισαγωγή από άλλο Excel»)

1. **Ανέβασμα**: xlsx / xls / csv, έως 15 MB και 5.000 γραμμές. Επιλογή φύλλου· αυτόματη εύρεση γραμμής επικεφαλίδων
   (αλλάζει)· προεπισκόπηση 5 γραμμών.
2. **Αντιστοίχιση στηλών**: για κάθε στήλη «τι είναι»:
   MTRL · κωδικός είδους · EAN · κωδικός κατασκευαστή · όνομα · σύντομη περιγραφή · περιγραφή · εγγύηση (μήνες) ·
   πλάτος / ύψος / βάθος (εκ.) · βάρος (kg) · μάρκα · κατηγορία · χαρακτηριστικό «<ετικέτα>» · τιμή κόστους (χωρίς ΦΠΑ) ·
   προτεινόμενη λιανική (με ΦΠΑ) · URL φωτογραφίας / banner / βίντεο · «Αγνόησε» (προεπιλογή).
   Αυτόματη πρόταση από το όνομα της στήλης (EAN/Barcode/GTIN, Image/Φωτογραφία…), εξήγηση και παράδειγμα τιμής κάτω από
   κάθε επιλογή. Για «χαρακτηριστικό» η ετικέτα προτείνεται από τις ετικέτες της ομάδας του τύπου.
3. **Αντιστοίχιση τιμών**: κάθε διαφορετική τιμή της στήλης μάρκας / κατηγορίας → δική μας μάρκα / τύπος (ομάδα
   χαρακτηριστικών + κατηγορία site), με πρόταση από το όνομα. Χωρίς αντιστοίχιση → κενό.
4. **Προεπισκόπηση** ανά γραμμή: Ενημέρωση (λίστα κενών που συμπληρώνονται, φωτογραφίες που προστίθενται, τιμή αν ήταν
   κενή) · Χωρίς αλλαγή · Νέο είδος · Σε αναμονή (χρειάζεται τον διακόπτη) · Πρόβλημα (με λόγο). Τσεκάρισμα / ξετσεκάρισμα,
   μαζικά ανά κατάσταση.
5. **Εκτέλεση** σε παρτίδες με πρόοδο: ενημερώσεις και φωτογραφίες αμέσως· νέα → λίστα έγκρισης.
6. **Αποθήκευση αντιστοίχισης** με όνομα (π.χ. «Προμηθευτής Χ»)· στην επόμενη εισαγωγή, αν οι επικεφαλίδες ταιριάζουν
   (υπογραφή), προτείνεται αυτόματα.

## 4. Κανόνες

**Εύρεση είδους** (από τον καθρέφτη — καμία κλήση SoftOne ανά γραμμή), με σειρά: MTRL → κωδικός είδους → EAN →
κωδικός κατασκευαστή + μάρκα (χωρίς μάρκα ο κωδικός κατασκευαστή δεν αρκεί). Αν δύο κλειδιά της ίδιας γραμμής δείχνουν
σε διαφορετικά είδη, ή το ίδιο είδος βρίσκεται σε δύο γραμμές του αρχείου → «Πρόβλημα».

**Μόνο κενά (υπάρχοντα)**: ένα πεδίο γράφεται μόνο αν είναι κενό στο SoftOne σήμερα· χαρακτηριστικά: προστίθενται μόνο
ετικέτες που δεν υπάρχουν στην περιγραφή (`composeMemo`)· φωτογραφίες: προστίθενται, όχι αντικατάσταση. Με κλειστό
διακόπτη: τα στοιχεία SoftOne «σε αναμονή» (κρατιούνται στην εισαγωγή και εκτελούνται αργότερα), οι φωτογραφίες (μόνο
site) εκτελούνται κανονικά.

**Νέα είδη (λίστα «Νέα είδη προς δημιουργία»)**: απαιτούνται κωδικός (μοναδικός, ≤ 25· προεπιλογή ο κωδικός
κατασκευαστή), όνομα, μάρκα / κατασκευαστής, τύπος (ομάδα χαρακτηριστικών), κατηγορία site· τα υπόλοιπα αντιγράφονται
από είδος ίδιου τύπου (όπως το `createItem`). Η λίστα δείχνει τι λείπει· «Έγκριση» (ένα-ένα ή μαζικά) μόνο σε πλήρη και
μόνο με ανοιχτό διακόπτη. Μετά τη δημιουργία: ανάγνωση / επαλήθευση, ανάγνωση του είδους στο κατάστημα (προβολή ενός
είδους), δέσιμο των φωτογραφιών που ανέβηκαν ήδη. Το νέο προϊόν μπαίνει **ανενεργό** στο site (ενεργοποίηση από τη
διαχείριση).

**Τιμή**: τιμή = κόστος × (1 + markup %) × (1 + ΦΠΑ του είδους), στρογγύλεμα του κανόνα (,90 · ,99 · ακέραιο · κανένα).
Αν υπάρχει προτεινόμενη λιανική και η τιμή τη ξεπερνά → η λιανική, με σήμανση. Γράφεται μόνο σε νέα είδη ή όπου η τιμή
web είναι κενή — ποτέ πάνω σε υπάρχουσα τιμή. Πεδίο SoftOne: τιμή web (MTREXTRA.NUM04) με setData ITEM, ίδιος
διακόπτης, ανάγνωση για επαλήθευση. Κόστος / κανόνας / περιθώριο φαίνονται στην προεπισκόπηση.

**Κανόνες markup** (σελίδα «Κανόνες τιμολόγησης», Κατάλογος → Templates & excel): γενικός κανόνας + εξαιρέσεις ανά μάρκα,
ανά κατηγορία (τύπο), ανά μάρκα + κατηγορία· ισχύει ο πιο συγκεκριμένος. Κάθε κανόνας: markup %, στρογγύλεμα, ενεργός.

## 5. Δεδομένα (μόνο προσθήκες, SQL μέσω DIRECT_URL — ποτέ db push)

- `ImportMapping`: id, name, headerSignature, sheet config (στήλη → πεδίο / ετικέτα χαρακτηριστικού), valueMaps (μάρκα,
  κατηγορία), createdById, timestamps.
- `ImportJob`: id, fileName, mappingId?, rows (κανονικοποιημένες γραμμές), counts, status (draft | applied | partial),
  createdById, timestamps.
- `PendingItem`: id, jobId, rowNo, code, fields, specs, brandId?, specGroupS1Id?, webCategoryId?, cost?, rrp?, price?,
  assetIds (φωτογραφίες ήδη στη βιβλιοθήκη), status (pending | created | error | discarded), mtrl?, error?, approvedById?,
  timestamps.
- `MarkupRule`: id, brandId?, categoryId?, percent, rounding (none | int | 90 | 99), active, timestamps.

## 6. Σχεδίαση κώδικα

- Καθαρή λογική (tests): εύρεση επικεφαλίδων, προτάσεις αντιστοίχισης, υπογραφή επικεφαλίδων, μετατροπή σε `ParsedRow` +
  γραμμές πολυμέσων, εύρεση είδους (διπλά / αμφίσημα), «μόνο κενά», markup + στρογγύλεμα + πλαφόν λιανικής, επιλογή
  κανόνα (πιο συγκεκριμένος).
- Server: εκτέλεση μέσω `planImport` / `applyImport` / `planMedia` / `applyMedia` (με επιλογή «μόνο κενά» και πεδίο τιμής)·
  λίστα νέων → `createItem` + εγγραφή τιμής.
- UI: οδηγός 4 βημάτων (ανέβασμα · στήλες · τιμές · προεπισκόπηση/εκτέλεση), λίστα «Νέα είδη προς δημιουργία», σελίδα
  «Κανόνες τιμολόγησης». ui-ux-pro-max, εξήγηση κάτω από κάθε πεδίο, χωρίς οριζόντια κύλιση από 360px, `data-help`,
  οδηγοί βοήθειας + help:gen.
