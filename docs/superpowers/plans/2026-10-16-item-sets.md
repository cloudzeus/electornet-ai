# Σετ ειδών ως προϊόντα Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Κάθε «Set ειδών» του SoftOne γίνεται προϊόν του καταλόγου· το κύριο είδος έχει «Πωλείται και μόνο του»· η παραγγελία σετ φτάνει στο SoftOne με γραμμές μελών και SPCS.

**Architecture:** Καθαρή λογική σε `lib/catalog/set-core.ts` (τιμή, απόθεμα, soldAlone, κωδικοί). Η προβολή `projectSetProducts()` (lib/softone/sets.ts) γράφει τα προϊόντα-σετ από τον καθρέφτη `S1Set`/`S1SetLine` + `S1Item` και υπολογίζει `soldAlone` των κύριων. Site: νέα πηγή `softone-set`, φίλτρο `soldAlone` στις λίστες, ανακατεύθυνση κύριου. Καταχώριση: στιγμιότυπο μελών στη γραμμή. Παραστατικό: ανάπτυξη σε γραμμές μελών.

**Tech Stack:** Next.js 16, Prisma (Postgres κοινός με live), node:test.

**Spec:** `docs/superpowers/specs/2026-10-16-item-sets-design.md`

## Global Constraints
- Σχήμα μόνο με SQL μέσω `DIRECT_URL` (ADD COLUMN IF NOT EXISTS), ποτέ `db push` / seed.
- SoftOne: μόνο αναγνώσεις.
- Κωδικοί προϊόντος-σετ: `erpCode = "SET-<spcs>"`, `sku = "SET-<code>"` (με πρόθεμα `S1-` αν πιαστεί), `source = "softone-set"`, Variant id `var_SET-<spcs>`.
- Προεπιλογή soldAlone: κύριο σε σετ εξαρτημάτων → όχι· αλλιώς ναι· `soldAloneMode` yes/no υπερισχύει.
- Παραστατικό: γραμμή κύριου με όλη την τιμή + μέλη με PRICE 0, όλες με `SPCS`.
- UI: ui-ux-pro-max, `min-h-11 md:min-h-9`, `var(--fs-…)`, χωρίς οριζόντια κύλιση από 360px, `data-help` κυριολεκτικά, help:gen.
- Push μόνο με «push it».

## Review Focus
- Κύριο είδος σε 2+ σετ με διαφορετικό είδος (εξαρτήματα + δώρο) → soldAlone «όχι» μόνο αν είναι κύριο σε σετ εξαρτημάτων (Task 2).
- Σετ με μέλος που λείπει από τον καθρέφτη τιμών (S1Item) → τιμή μέλους 0, όχι σφάλμα (Task 2/3).
- Κύριο χωρίς ενεργό σετ αλλά `soldAloneMode = no` → ο διαχειριστής το έκλεισε ρητά: μένει εκτός λιστών (Task 2).
- Ανακατεύθυνση κύριου προς ανενεργό σετ → όχι ανακατεύθυνση· 404 μόνο αν δεν υπάρχει κανένα ενεργό σετ και soldAlone όχι (Task 4).
- Παραγγελία σετ όταν άλλαξαν τα μέλη στο SoftOne μετά την αγορά → το παραστατικό βγαίνει από το στιγμιότυπο `setParts` (Task 5/6).
