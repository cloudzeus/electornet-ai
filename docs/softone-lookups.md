# SoftOne → βασικοί πίνακες (διαχειριστικό)

`/admin/softone` (group **SoftOne ERP** στο μενού). Δικαίωμα: `settings.integrations.write`.

## Αρχή λειτουργίας
Κάθε πίνακας αναφοράς του SoftOne έχει **δικό μας μοντέλο** στη βάση. Η γραμμή κρατά δύο στρώσεις:

| Στρώση | Στήλες | Ποιος είναι ο «κύριος» |
|---|---|---|
| Δικά μας | `code`, `name`, `active` + τα ειδικά ανά πίνακα (π.χ. `provider`, `carrier`, `purpose`, `logo`, `region`) | **Εμείς.** Ο συγχρονισμός δεν τα ξαναγράφει ποτέ. |
| Καθρέφτης S1 | `s1Id`, `s1Name`, `s1Data` (όλη η γραμμή όπως ήρθε), `s1SyncedAt`, `s1Missing` | **SoftOne.** Ενημερώνεται σε κάθε συγχρονισμό. |

- Πρώτη εμφάνιση γραμμής → δημιουργείται με τα δικά μας πεδία αρχικοποιημένα από το SoftOne.
- Γραμμή που έπαψε να υπάρχει στο SoftOne → σημαδεύεται `s1Missing`, **δεν** διαγράφεται (μπορεί να τη χρησιμοποιούν παραγγελίες).
- Γραμμή δική μας χωρίς αντίστοιχη στο ERP (π.χ. τρόπος αποστολής «ACS») → `s1Id` κενό, «δική μας» στη λίστα.

## Πηγές ανάγνωσης (μόνο reads στο ERP)
- **`GetTable`** (TABLE / FIELDS / FILTER) για τους περισσότερους πίνακες.
- **`getBrowserInfo` + `getBrowserData`** όπου το GetTable είναι ελλιπές. Αφορά τη `SERIES`: το GetTable επιστρέφει 23 γραμμές, ο browser 164 — εκεί είναι οι σειρές παραγγελιών e-shop (PES). Οι τιμές του browser έρχονται σε μορφή `id|label` και κρατάμε το `id`.

### Αυτόματη αναγνώριση κατά τον πρώτο συγχρονισμό
- **Τρόποι πληρωμής**: από το όνομα → `cod` (Αντικαταβολή), `paypal`, `card` (Κάρτα), `bank` (Έμβασμα), `loan` (EurobankLoans), `cash`.
- **Σειρές**: `PES` → Παραγγελία e-shop, `Τ-PES` → Τηλεφωνική, `PES-PL` → Πληρωμένη, «Πιστωτικό…» → credit, «Προσφορά» → quote.
Όλα αλλάζουν από τη λίστα· η αντιστοίχιση είναι δική μας και επιβιώνει των επόμενων συγχρονισμών.

## Λογότυπα μαρκών
Στη λίστα Μάρκες, «Επεξεργασία» → πεδίο **Λογότυπο**: ανοίγει τη Media library (επιλογή ή upload). **SVG μένει vector** (το pipeline δεν το ραστεροποιεί, φτιάχνει μόνο raster thumbnail για preview), PNG/WebP περνούν από την κανονική επεξεργασία. Το αρχείο αποθηκεύεται στο Bunny CDN.

## Συγχρονισμός
- Κουμπί ανά πίνακα ή «Συγχρονισμός όλων» στο `/admin/softone`.
- Ιστορικό όλων των εκτελέσεων: `/admin/softone/sync` (γραμμές, νέες, ενημερωμένες, όσες λείπουν, χρόνος, σφάλματα).
- Αυτόματα: `GET /api/cron/softone-lookups` με `Authorization: Bearer $CRON_SECRET`, π.χ. κάθε νύχτα:
  ```
  0 4 * * *  curl -fsS -H "Authorization: Bearer $CRON_SECRET" https://www.euronics.gr/api/cron/softone-lookups
  ```
- Κάθε εκτέλεση γράφει `S1SyncRun` και audit log. Ο συγχρονισμός είναι batched (ένα `createMany`, στοχευμένα updates μόνο όπου άλλαξε ο καθρέφτης).
