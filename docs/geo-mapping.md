# Γεωδεδομένα: περιφέρειες, νομοί, Τ.Κ. — mapping με SoftOne και τα geo API

Ενιαία ιεραρχία για όλο το site (`lib/geo/regions.ts`, καθαρό module, το χρησιμοποιούν και server και storefront):

```
Περιφέρεια (13)  →  Νομός / περιφερειακή ενότητα (51)  →  Τ.Κ. (1.201)  →  πόλη  →  lat/lng
```

## Γιατί χρειάζεται κανονικοποίηση
Η ίδια περιοχή φτάνει σε εμάς με τρεις γραφές:

| Πηγή | Μορφή | Παράδειγμα |
|---|---|---|
| SoftOne `DISTRICT` | γενική, κεφαλαία, χωρίς τόνους | `ΑΤΤΙΚΗΣ`, `ΠΕΛΛΗΣ`, `ΚΕΦΑΛΛΗΝΙΑΣ` |
| Store locator euronics.gr | ονομαστική με τόνους | `Αττική`, `Πέλλα`, `Κεφαλονιά` |
| Geocoding (Nominatim) / IP (ipapi) | ονομαστική ή αγγλικά | `Περιφέρεια Αττικής`, `Attica`, `Central Macedonia` |

Το `foldGreek()` (κεφαλαία, χωρίς τόνους, χωρίς τελικό «Σ») ρίχνει και τις τρεις στο ίδιο κλειδί· επιπλέον υπάρχει λίστα συνωνύμων (πόλη → νομός, λατινικά → ελληνικά).

**Επαλήθευση:** και οι 51 νομοί του SoftOne αντιστοιχήθηκαν σε περιφέρεια, και τα 252 καταστήματα αναγνωρίστηκαν, και οι 1.201 Τ.Κ. συνδέθηκαν με νομό.

## Αντιστοίχιση πηγών
| Έννοια | SoftOne | Geocoding / IP | Δικό μας |
|---|---|---|---|
| Περιφέρεια | *δεν υπάρχει* | `state` / `region` (Nominatim), `region` (ipapi) | `District.region` — **δική μας προσθήκη**, οδηγεί τις ζώνες αποστολής |
| Νομός | `DISTRICT` (51) | `county` / `state_district` | `District.name` + `District.s1Id` |
| Τ.Κ. | `ZIP` (`ZIP.CODE`, `ZIP.DISTRICT`) | `postcode` | `PostalCode.code` + `districtId` |
| Πόλη | *δεν υπάρχει πίνακας* — ελεύθερο κείμενο στο `CUSTOMER.CITY` | `city` / `town` / `village` | `PostalCode.city`, `Address.city`, `Store.city` |
| Χώρα | `COUNTRY` (ISO-2) | `country_code` | `Country.code` |
| Συντεταγμένες | *δεν υπάρχουν* | `lat` / `lon` | `Store.lat/lng`, `Address.lat/lng` |

**Το SoftOne δεν έχει πίνακα πόλεων ούτε περιφερειών.** Η πόλη είναι ελεύθερο κείμενο στη διεύθυνση του πελάτη και η περιφέρεια δεν υπάρχει καθόλου — γι' αυτό τη συμπληρώνουμε εμείς από το `lib/geo/regions.ts`.

## Πίνακες που κρατούν γεωδεδομένα
| Μοντέλο | Πεδία | Πώς γεμίζουν |
|---|---|---|
| `District` | `code`, `name`, `region`, `s1Id` | συγχρονισμός `DISTRICT` + περιφέρεια από το taxonomy |
| `PostalCode` | `code`, `city`, `districtId`, `s1Id` | συγχρονισμός `ZIP`· η πόλη από geocoding/χειροκίνητα |
| `Country` | `code` (ISO-2), `eu`, `currency` | συγχρονισμός `COUNTRY` |
| `Store` | `lat`, `lng`, `city`, `zip`, `region`, `geoLat/geoLng`, `geoDeltaKm`, `geocoded` | import από euronics.gr + Nominatim· `region` = **νομός** (ιστορικά) |
| `Address` (πελάτη) | `street`, `number`, `city`, `zip`, `region`, `lat`, `lng`, `geoSource`, `geoLabel`, `nearestStoreId`, `nearestKm` | `geocodeCustomerAddress()` — Nominatim + πλησιέστερο κατάστημα· το `region` κανονικοποιείται από το Τ.Κ. |
| `Customer` | `preferredStoreId` | από την προεπιλεγμένη διεύθυνση |
| `Warehouse` | `storeId` | χειροκίνητη αντιστοίχιση αποθήκης ERP ↔ κατάστημα |
| `SnapScan`, `Consent`, `LoginEvent` | `ipHash` (όχι θέση) | τεκμήρια GDPR |
| cookie `eu_geo` | `lat`, `lng`, `city`, `source` | GPS, περιοχή που έγραψε ο επισκέπτης, ή IP |

> Προσοχή στη διφορούμενη ονομασία: το **`Store.region` και το `Address.region` κρατούν νομό**, όχι περιφέρεια (ιστορικός λόγος — έτσι δημοσιεύει ο store locator). Η περιφέρεια βγαίνει πάντα με `regionOf({ zip })` ή από το `District.region`.

## API
| Σκοπός | Πηγή | Πού |
|---|---|---|
| Διεύθυνση → συντεταγμένες | **Nominatim** (OpenStreetMap), `countrycodes=gr`, 1 κλήση/δευτ. | `lib/stores/geocode.ts` |
| Επισκέπτης → περιοχή | GPS → cookie `eu_geo` → Cloudflare headers → **ipapi.co** (Ρυθμίσεις → AI) | `lib/geo/ip.ts` |
| Πλησιέστερο κατάστημα | haversine πάνω στα ενεργά καταστήματα | `nearestStore()` |

## Συναρτήσεις
```ts
districtByName("ΑΤΤΙΚΗΣ" | "Αττική" | "Attica")  // → { s1: 5, name: "Αττική", region: "Αττική", … }
districtByS1(19)                                  // → Θεσσαλονίκη / Κεντρική Μακεδονία
districtByZip("54622")                            // → Θεσσαλονίκη (2 πρώτα ψηφία)
regionOf({ zip: "19003" })                        // → "Αττική"
districtsOfRegion("Κρήτη")                        // → Ηράκλειο, Λασίθι, Ρέθυμνο, Χανιά
```
Προτεραιότητα στο `regionOf`: κωδικός SoftOne → Τ.Κ. (πιο αξιόπιστο) → όνομα.
