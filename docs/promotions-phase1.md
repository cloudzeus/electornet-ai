# Προσφορές · Φάση 1 — λίστα ελέγχου

Κανόνας: **καμία κλήση προς το SoftOne** μέχρι ρητή εντολή. Τα παραστατικά μένουν σε προεπισκόπηση (`ErpSync.status = preview`).

## Α. Μηχανή — μηχανισμοί
- [ ] 1+1 / 2+1 (`n-plus-m`) — το φθηνότερο δωρεάν ανά ομάδα
- [ ] 2ο / 3ο −Χ % (`nth-discount`)
- [ ] Κλιμακωτή ποσότητα (`qty-tiers`)
- [ ] Δώρο με αγορά (`gift`) — γραμμή με αξία και έκπτωση 100 %
- [ ] Δωρεάν υπηρεσία (`service`) — εγγύηση, ανακύκλωση, απομάκρυνση· εγκατάσταση ανενεργή
- [ ] Δωρεάν μεταφορικά (`shipping`)
- [ ] Υποδείξεις καλαθιού («πρόσθεσε 1 ακόμη…», «σου λείπουν Χ €…»)
- [ ] Τεστ για όλα

## Β. Ταχύτητα — έτοιμες τιμές
- [ ] `ProductOffer`: τελική τιμή, tags, λήξη, χαμηλότερη τιμή 30 ημερών ανά προϊόν
- [ ] Επαναϋπολογισμός σε δημοσίευση / αλλαγή / έναρξη / λήξη (χρονοπρογραμματιστής) μόνο για όσα αλλάζουν

## Γ. Βιτρίνα
- [ ] Τιμή προσφοράς + «χαμηλότερη τιμή 30 ημερών» σε λίστες και σελίδα προϊόντος
- [ ] Tags (έως 2 ανά κάρτα), countdown λήξης
- [ ] Καλάθι / checkout: δώρο, δωρεάν υπηρεσία, δωρεάν μεταφορικά, υποδείξεις
- [ ] Κουπόνια πρώτης αγοράς / newsletter: έκδοση και email

## Δ. Διαχειριστικό
- [ ] Λίστα προσφορών (KPIs, φίλτρα, κατάσταση, μαζικές ενέργειες)
- [ ] Οδηγός: πρότυπα → προϊόντα → κανόνες → εμφάνιση → έλεγχος (συγκρούσεις, κάτω από κόστος, έγκριση)
- [ ] Εκδόσεις, έγκριση δεύτερου προσώπου πάνω από όριο, audit
- [ ] Προσομοιωτής καλαθιού
- [ ] Ημερολόγιο με επικαλύψεις και επιθεωρητή SKU / ημέρας
- [ ] Κανόνες επικάλυψης (δικλείδες)
- [ ] Κουπόνια (κοινά, μοναδικά, παρτίδες)
- [ ] Tags (εμπορικά αυτόματα, ενημερωτικά χειροκίνητα / αυτόματα)

## Ε. Πολλοί τρόποι
- [ ] Από την καρτέλα προϊόντος και μαζικά από τη λίστα
- [ ] Excel (ειδικές τιμές)
- [ ] Αντιγραφή καμπάνιας
- [ ] Ερμής: περιγραφή → προσυμπληρωμένος οδηγός

## ΣΤ. Αναφορές, landing pages, διαφημιστικές θέσεις
- [ ] Αναφορά ανά καμπάνια · ανά παραστατικό (όροι όπως ίσχυαν, προεπισκόπηση ERP)
- [ ] Landing pages με blocks
- [ ] Διαφημιστικές θέσεις (banners δεμένα με προσφορά)
