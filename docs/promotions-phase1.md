# Προσφορές · Φάση 1 — λίστα ελέγχου

Κανόνας: **καμία κλήση προς το SoftOne** μέχρι ρητή εντολή. Τα παραστατικά μένουν σε προεπισκόπηση (`ErpSync.status = preview`).

## Α. Μηχανή — μηχανισμοί
- [x] 1+1 / 2+1 (`n-plus-m`) — το φθηνότερο δωρεάν ανά ομάδα
- [x] 2ο / 3ο −Χ % (`nth-discount`)
- [x] Κλιμακωτή ποσότητα (`qty-tiers`)
- [x] Δώρο με αγορά (`gift`) — γραμμή με αξία και έκπτωση 100 %
- [x] Δωρεάν υπηρεσία (`service`) — εγγύηση, ανακύκλωση, απομάκρυνση· εγκατάσταση ανενεργή
- [x] Δωρεάν μεταφορικά (`shipping`)
- [x] Υποδείξεις καλαθιού («πρόσθεσε 1 ακόμη…», «σου λείπουν Χ €…»)
- [x] Τεστ για όλα

## Β. Ταχύτητα — έτοιμες τιμές
- [x] `ProductOffer`: τελική τιμή, tags, λήξη, χαμηλότερη τιμή 30 ημερών ανά προϊόν
- [x] Επαναϋπολογισμός σε δημοσίευση / αλλαγή / έναρξη / λήξη (χρονοπρογραμματιστής) μόνο για όσα αλλάζουν

## Γ. Βιτρίνα

- [x] Καλάθι / checkout: δώρο, δωρεάν υπηρεσία, δωρεάν μεταφορικά, υποδείξεις — από τον server· ο κωδικός κουπονιού περνά από το καλάθι στο checkout
