# Προσφορές · Φάση 2 — στόχευση και συνδυασμοί

Κανόνας: **καμία κλήση προς το SoftOne** μέχρι ρητή εντολή. Τα παραστατικά μένουν σε προεπισκόπηση.

## Βοήθεια χρήστη
- [x] «Τι κάνω εδώ;» σε κάθε σελίδα και σε κάθε βήμα του οδηγού (θυμάται αν το έκλεισες)
- [x] «i» σε κάθε πεδίο με εξήγηση και παράδειγμα
- [x] Κέντρο βοήθειας `/admin/prosfores/voitheia`: οδηγοί βήμα-βήμα, ζωή προσφοράς, γλωσσάρι, συχνές ερωτήσεις

## Μηχανή
- [x] Μαζί φθηνότερα (`together`): βασικό + συνοδευτικό με έκπτωση (ένα ανά βασικό, πρώτα το ακριβότερο), υπόδειξη
- [x] Πακέτο σε σταθερή τιμή (`bundle`): έκπτωση μοιρασμένη αναλογικά στις γραμμές (DISC1VAL)
- [x] Έκπτωση τρόπου πληρωμής (`payment-percent` / `payment-amount`) → DISC3VAL, υπόδειξη στο καλάθι, γραμμή στο checkout
- [x] Κοινά πελατών (segments) στους κανόνες
- [x] Early access για κοινά (ώρες πριν την έναρξη)

## Κοινά & κουπόνια
- [x] Κοινά πελατών: κριτήρια, μέλη τώρα, ενημέρωση μόνα τους — `/admin/prosfores/koina`
- [x] Προσωποποιημένα κουπόνια σε κοινό (email μόνο με συναίνεση marketing)
- [x] Κουπόνι επόμενης αγοράς (μετά από κάθε παραγγελία· φαίνεται στη σελίδα επιβεβαίωσης, email με συναίνεση)
- [x] Κουπόνι γενεθλίων (cron μία φορά την ημέρα, ένα τον χρόνο, με συναίνεση)
- [x] Εγκαταλελειμμένο καλάθι: υπενθύμιση με email και προαιρετικό κουπόνι (cron ανά 15′, μία φορά ανά καλάθι, με συναίνεση)

## Ανενεργά μέχρι διευκρίνιση (υποδομή, κλειδωμένα)
- Δωροεπιταγή με αγορά · Τραπεζική προσφορά · Κλήρωση με αγορά · Giveaway · Δωρεάν εγκατάσταση

Όλα τα αυτόματα (γενέθλια, επόμενη αγορά, υπενθύμιση καλαθιού) είναι **κλειστά** μέχρι να οριστεί προσφορά-κουπόνι / να ενεργοποιηθούν στους «Κανόνες».
