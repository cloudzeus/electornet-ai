# Προσφορές · Φάση 3 — με δεδομένα και με τρίτους

Κανόνας: **καμία κλήση προς το SoftOne** μέχρι ρητή εντολή.

## Προσωποποιημένες προσφορές
- [x] Προσωπικός κωδικός που ισχύει μόνο σε συγκεκριμένο προϊόν / κατηγορία (`Coupon.scope`)
- [x] Κανόνες: λίστα επιθυμιών · αντικατάσταση παλιάς συσκευής · καλάθι που έμεινε · συμπληρωματικά μετά από αγορά
- [x] Έκδοση κάθε πρωί (cron), μία ανά πελάτη ανά αφορμή, email μόνο με συναίνεση
- [x] «Οι προσφορές μου» στον λογαριασμό του πελάτη
- [x] Διαχειριστικό: ρύθμιση κανόνων, προεπισκόπηση (ποιος θα πάρει τι), έκδοση τώρα, αποτελέσματα

## Κατάστημα / ταμείο
- [x] Προσφορά μόνο για παραλαβή από συγκεκριμένα καταστήματα
- [x] Κανάλι «Ταμείο καταστήματος» (POS)
- [x] POS API (μόνο υπολογισμός, με API key «pos») — ίδια μηχανή, ίδιοι κωδικοί, αντιστοίχιση DISC1/2/3

## Ανενεργά μέχρι διευκρίνιση
- Cashback (τράπεζα ή συνεργάτης): ποιος πληρώνει, πότε επιστρέφεται, πώς αποδεικνύεται η αγορά

## Σημειώσεις
- Σήμερα τα δεδομένα για προσωποποίηση είναι λίγα (0 παραγγελίες, οι λίστες επιθυμιών δείχνουν δοκιμαστικά προϊόντα): η προεπισκόπηση βρίσκει 2 υποψήφιους από φωτογραφίες συσκευών. Όλοι οι κανόνες είναι **κλειστοί** μέχρι να τους ανοίξει ο υπεύθυνος.
- Η «φωτογραφία συσκευής» μετρά ως πρόθεση αντικατάστασης ακόμη κι όταν δεν εκτιμήθηκε ηλικία.
- POS: μόνο υπολογισμός (docs/pos-api.md). Η καταγραφή πωλήσεων ταμείου θα έρθει από το SoftOne.
